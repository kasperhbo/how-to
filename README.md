# how-to

Collection of short how-to guides, mainly for Unreal Engine and game development workflows.

## Layout

Each topic has its own folder. Each how-to has its own subfolder with a `README.md`.

```
<topic>/<how-to-name>/README.md
```

Put images and sample files for a how-to in the same subfolder as its `README.md`.

## Index

### Perforce

- [Shelving work in Perforce](perforce/shelving/README.md): reconcile offline work, shelve it, and revert local changes.

## Adding a how-to

1. Pick an existing topic folder, or create a new one (lowercase, hyphenated).
2. Create `<topic>/<how-to-name>/README.md`.
3. Add a link to the index above.
